## Answer

**Agree with changes** to the static, open browsing collection. A path and numbered stops can express an editorial arrangement without asserting that the product assessed a learner's readiness. Keep every catalog-available stop open and make selection visibly different from completion. The current interaction specification meets this boundary in words; no rendered mockup or working artifact was available to this review, so its visual execution remains unchecked.

Use **Number Island**, **collection**, **area** and **stop** as the main vocabulary. Prefer those to a visible “Level 1” label: a numbered level beside a mountain summit can suggest an attainment ladder even when every stop is open. If owners retain “level” as a decorative collection identifier, pair it with the open-browsing instruction and never show an earned level, next-level gate or completion fraction. This is a copy recommendation for design-lead, not a change to the accepted twelve-lesson sequence.

## Literal navigation copy

| Surface | Permitted label or pattern | Constraint |
|---|---|---|
| Catalog entry | **Explore Number Island** | Ordinary optional navigation; leave feed behavior unchanged. |
| Page title | **Number Island** | No promise of mastery, complete coverage or assessed progression. |
| Collection line | **Mathematics · {available count} lessons** | Count the currently visible collection, not visits or completed lessons. |
| Instruction | **Choose any stop to explore a lesson.** | Visible in the first screen; no “start here to unlock” framing. |
| View controls | **Map** / **List** | Accessible names: **Map view** / **List view**. Neither is a progress view. |
| Area controls | **Number Village** / **Fraction Harbour** / **Scaling Mountain** | Decorative places; not ability bands or unlocked regions. |
| Detail context | **Selected stop {number} · {landmark}** | Selected only, never reached, earned, finished or completed. |
| Lesson title/status | Exact catalog title and canonical status label | “Published” is publication metadata, not “verified,” “mastered” or a quality badge. |
| Player action | **Open lesson** | Accessible name identifies the exact lesson title; selection alone does not launch it. |
| Player return | **Back to Number Island** | Restores bounded navigation selection, not completion. |
| Empty area | **No lessons available in this area** | No “locked,” “come back tomorrow” or countdown. |
| Empty collection | **No lessons available in this collection** | Provide the ordinary **Curriculum** link. |
| Optional announcement | **Selected stop {number}: {exact title}** | Announce navigation context only, without celebration or achievement. |

Use **Feed** and **Curriculum** for ordinary exits. Keep lesson-specific teaching in the existing player rather than adding a new map explanation or challenge.

## Changes and prohibited implications

- Do not use **Your next step**, **Ready for you**, **Continue your journey**, **Complete the island**, **Master Number Island**, **Unlock**, **Earn**, **Daily streak**, **Keep your streak** or **Only one lesson left**. These require assessed readiness, retained learner state, coercive progression, or an outcome claim that this version does not have. A future separately owned feature could propose appropriate language with evidence; it is not in this scope.
- Show the selected marker with an outline and a textual selected state. Do not use a checkmark, filled trail, stars, trophies, confetti or a selected-count fraction as selection feedback. A summit/flag may remain unchanging scenery, never an earned destination.
- Do not describe clicks, opened lessons, route position or returning from a player as learning, recall, completion or mastery. Do not add a **Mark done** control.
- No learner-history, progress, identity or store read/write is needed for these labels. No cookies, browser storage, new tracking, experiment assignment, rewards, locks, automatic advance or return reminders are authorized by this review. Current URL/component selection is navigation only, within the VP's allowlist.
