# Build note: one-recipe-for-sixty (demo-builder, 2026-10-12)

- Intent: the learner chooses the first split of 60 (five buttons); the tree then grows level by level to primes, coloured by prime. Each tree goes on a shelf with its primes sorted, so the identical 2 2 3 5 rows do the arguing.
- Deviation from brief: the learner chooses only the first split; lower splits use the factor pair nearest the square root (so trees look as different as possible). A per-node choice would need tappable SVG nodes, which QA's press-every-control loop cannot exercise reliably.
- Reveal unlocks after three different starts.
