## Pre-flight v1

1. Titles and hooks do not state the answer. The initial stage has two empty panels, so there is no pictorial hook before prediction; a design reviewer should decide whether a neutral organism image would improve engagement without giving away evidence.
2. Each question has three verbal options. Distractor quality and specificity remain for independent pedagogy review; several are intentionally broad or easy.
3. Both comparison buttons are locked during prediction; no evidence state or caption is visible.
4. One button opens the first state and one opens the second. Both diagrams and labels stay visible, supporting the comparison named in the reveal. The nautilus chamber conditions are stipulated model states, not observations.
5. Both controls are in DOM order and require separate first activations. Repeated clicks are guarded by refs so they cannot unlock reveal alone. Buttons declare 44 × 44 px minimum dimensions, but actual layout and interaction timing have not been tested in a browser.
6. There is no stage reset. Reload should reset the component, but this has not been verified in a browser.
7. No 390 × 844 screenshot, text-floor measurement, contrast, keyboard or screen-reader review has been completed. Some text labels may fail the size floor, and a few representations—especially the nautilus and cladogram—need richer, scientifically reviewed organism context.
