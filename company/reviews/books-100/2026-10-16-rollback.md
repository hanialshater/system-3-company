# Books100 grouped source rollback

This is a reviewable repository rollback plan, not a performed rollback or production deployment approval. Shared renderer/model, all100 additions, curriculum, new works, generated registration and focused Books tests move as one unit. Operational history and independent review records remain. No migration or external learner store exists.

Run from the repository root after fetching the final PR branch; these commands create an isolated rollback worktree. The integrated default base `a4cc732b734bbe06f13afcf75e6c52fe651730b0` is the exact comparison endpoint. Using it preserves the independent upstream lessons and metadata merged during this task. The task-owned branch reference captures QA-evidence metadata as well as frozen rendering source. Review the patch before applying; a conflict from later dependent work requires a new coordinated rollback.

```sh
git fetch origin
git worktree add --branch revert/books100 .claude/worktrees/books100-revert origin/feat/books-100-demos
cd .claude/worktrees/books100-revert
mkdir -p artifacts
git diff --binary a4cc732b734bbe06f13afcf75e6c52fe651730b0 origin/feat/books-100-demos -- src/demos/books src/components/books src/lib/books content/curriculum/books.json content/works.json src/demos/index.generated.ts src/demos/loaders.generated.ts tests/books > artifacts/books100-source-revert.patch
git apply --reverse --index --check artifacts/books100-source-revert.patch
git apply --reverse --index artifacts/books100-source-revert.patch
npm ci
npm run registry
npm run check
npm run typecheck
NEXT_DIST_DIR=.next-books100-rollback npm run build
git restore --source=HEAD --worktree -- tsconfig.json
```

Before committing the rollback, independently test the six original Books routes on phone/desktop, confirm the100 removed routes are absent, run feed checks and report inherited failures without weakening them. Use a single exactPID server lifecycle and the same rollback dist for server and tools. No code from src/kit, tests/qa, deploy configuration or company history is reverted by this patch. Only then stage regenerated registry files and commit the source rollback for review.
