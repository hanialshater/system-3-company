## Environment adaptation

The execution environment isolates localhost between command lifecycles. Each run therefore starts its own explicit `127.0.0.1:3612` Next process, waits for HTTP readiness, and launches browser commands as children in the same lifecycle. Default host discovery also fails with `uv_interface_addresses`, so the start command uses `-H 127.0.0.1`. The process is tracked by an ignored PID file and stopped by its exact child PID in `finally`; no global kill, build, server-wrapper change, test or configuration change was made. The six-lesson build was supplied by the integrator at the commit above.

Ignored runner and logs: `artifacts/.serve/books100-pilot-qa.mjs`, `artifacts/.serve/books100-pilot-3612.pid`, `artifacts/.serve/books100-pilot-3612.log`; lifecycle record: `artifacts/books100-pilot-lifecycle.json`.
