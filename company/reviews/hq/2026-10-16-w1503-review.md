## What holds (checked in the code)

- Gate: page and route both call `hqEnabled()` (404), and `runSim` refuses in production even with `HQ_PUBLIC=1` (`simLocal`). So the lab never spawns a process on a deployed build. (hq-personalization-server.ts:13, route.ts:11)
- Argument safety: `execFile` with no shell; every argv element is built by `cliArgs` from a parsed `SimRequest`. Ids match `^[a-z0-9-]{1,48}$`, saved files match `^[a-z0-9-]+\.[a-z0-9-]+\.seed\d{1,3}\.json$` (no slash, so no traversal), numbers are integer-bounded (days 1..14, seed 1..999, seeds 1..10).
- Boundary: the app never imports the model; only the server file names `company/personalization/model/sim/hq-cli.mjs` (W-1498).
- Library link `/hq/library/personalization/model/README.md` resolves under the library's company/-relative path guard.
- Timeline index: the simulator numbers steps as `steps.length` (simulate.mjs:122, :146), so `trace.steps[stepNo]` is correct.

## Findings (not fixed unless marked)

1. FIXED, trivial. HqTop.tsx header comment said it served only /hq/design and /hq/curriculum; it serves every /hq/* page except /hq. Comment now says so.
2. Tab list is duplicated by hand in HqTop.tsx `TABS` and HQ.tsx (eight `<Link>` blocks). The comment asks for the same order but nothing tests it; the next tab will drift. Suggest exporting `TABS` and mapping it in HQ.tsx, or a test that greps both lists. Owner: hq-engineer (small).
3. No concurrency cap on `runSim`. Each page load spawns a Node process (`meta`), each Compare can run up to 10 seeds x all personas with a 90 s timeout and a 64 MB buffer, and repeated clicks or a second tab stack processes. Local-only, so low risk; a single in-flight lock per route would remove it. Owner: personalization-engineer (code is theirs) or hq-engineer.
4. `execFile`'s timeout kills the Node child only. If the CLI ever spawns children, they would survive. Today it does not appear to; note for any future change to hq-cli.mjs.
5. Page SSR runs `meta` on every request (`force-dynamic`), then the client immediately fires a `run`. Two spawns per visit; the meta call could be cached for the process lifetime keyed on the mtime of the model folder. Cosmetic locally.
6. Error shape: route returns 422 for any simulator failure, including "persona not found" from the CLI, which is closer to 400/404. Clients only read `j.error`, so no effect today.
7. `parseSimRequest` takes `Number("1e2")` as 100 and `Number(" 3")` as 3, so some odd strings pass as integers. Bounded by the ranges, harmless.
8. The tab key `HqTab` union grew to 8; at narrow widths the tab row may wrap or scroll. Not checked in a browser. Owner: hq-engineer, next UI pass.
9. Room seats for the new personalization org were a separate gap (W-1524): done in the same commit series, see company/ops/progress.md.
