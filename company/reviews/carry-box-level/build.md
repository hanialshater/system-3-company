# Build note: carry-box-level

builder: demo-builder · 2026-10-13 · for evaluators to read after their findings

- Design intent: side view at one scale; a 10 kg box carried 20 m along one of three paths (straight up, a 30 degree ramp, a level floor). The arms' force (98.1 N up) is drawn as a red arrow on the box; the height gained is a green dashed bracket ("up 10 m", "up 0 m"). The caption shows the product: 98.1 N x height gained = work.
- Vocabulary trap guard: the physics word "work" is defined on the stage before the prediction ("Work = force x distance moved along the force, in joules"), so the question tests applying it to a vertical push and a level motion, not knowing a definition. Options are 0 J / 98 J / 1962 J (98.1 N x 20 m, the "force times distance walked" error), changed from the brief's 196 J, which matched no path.
- Departure from the brief: three path buttons instead of an angle slider, so the QA path can end on the level floor.
- Earned reveal: milestones 'lift' (any rising path chosen) and 'level'. The ramp is the starting path; QA presses Straight up, then the ramp, then Level floor, so the last screen is the question's state. The reveal quotes 0 J, and 981 J and 1962 J only for paths the learner saw.
- Numbers (node): 10 x 9.81 = 98.1 N; rises 0, 10.0, 20 m; work 0, 981, 1962 J.
- Idealisation on stage: steady speed (arms just hold the box up); starting and stopping are ignored (claim c2).
- After screenshots: shrank the "10 kg" label to fit the box.
