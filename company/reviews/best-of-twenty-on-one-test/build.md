# Build note: best-of-twenty-on-one-test (demo-builder, wave-i-ai, 2026-10-14)

Brief: `company/domains/briefs/ai.ml-basics.md` item 58. Status draft, version 1. Claims c1-c5 unverified; c4 (Dwork et al. 2015, ESL 7.2) is a real-systems citation for the fact-checker.

- Stage: a single score axis (30-70%). Each model is a dot, stacked so none overlap, and the winner is ringed with "winner N". A dashed fresh-test line sits below; after "Fresh test", the winner's fresh score appears there as a dot, with a connector. Readouts: "Winner, shared test" and "Winner, fresh test". Message line: once the winner has been fresh-tested, "Seen: seed s, 20 models: winner w, fresh f%."
- Seeds: mulberry32(seed) scores the shared test and mulberry32(seed + 100000) the fresh test. Seeds go 1, 2, 3, ... in press order, untuned (seed 1: winner 56, fresh 49.7%). Model buttons re-run the current seed, so the first m models of a bigger board are the same models.
- Controls in DOM order: Run leaderboard, Fresh test, Models 1 / 5 / 20 / 100 (the active one is disabled).
- Milestones: question-run (a 20-model run), fresh-scored (fresh test on a 20-model run; seed, winner and fresh recorded), crowd-seen (a run with 1, 5 or 100 models; m and winner recorded).
- Departures from the brief: (1) the fresh test has 1,000 questions, not 100. With 100, seed 1 re-scored the winner at 62 against its 56, so one run could show the opposite of the point. With 1,000 the fresh score is 50% plus or minus about 1.6 points (seeds 1-5,000: fresh reached the winner's score in 6 runs, and the reveal has a branch for that). (2) Options are "About 50% / 60% / 75%" (brief: 50 / 59 / 75), because "59%" was the only exact-looking number (No answer before the commit). The exact 59.31 is in c1. (3) No Reset: the trace line and readouts carry the state. (4) The reveal adds one sentence quoting the learner's crowd run ("Your best of 100 reached 59: more competitors, a luckier winner.") in place of the told "The more models compete, the higher a skill-free winner climbs." It falls back to a told sentence (c3) only if the crowd run contradicts on that seed pair. Reveal 75 words on the QA path; the brief draft was 74.
