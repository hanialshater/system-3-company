# Wave 4: the preprocessor and variadic functions

Read CONTRACT.md first. W1-W3 stay in scope (regressions). From this wave on, most tests `#include` the provided
headers (CONTRACT.md section 3), so your compiler must parse them.

## In scope

- **`#include <name.h>`.** Searched in the `-I` directories in order, with include guards (`#ifndef X / #define X`).
  Only the provided headers are ever included.
- **`#define`:**
  - object-like and function-like macros, including empty bodies and parameterless `f()`;
  - nested expansion, and recursion prevention (a macro is not re-expanded inside its own expansion);
  - arguments expanded before substitution, except next to `#` and `##`;
  - `#` stringizing and `##` token pasting;
  - variadic macros with `...` and `__VA_ARGS__`;
  - `#undef`.
- **Conditionals:**
  - `#if`, `#ifdef`, `#ifndef`, `#elif`, `#else`, `#endif`, nested;
  - `defined X` and `defined(X)`; integer constant expressions with the C operators; undefined names are 0;
  - skipped groups are not processed, except for nesting, and may hold anything, including `#error`.
- **Predefined macros.** `__LINE__`, `__STDC__`, `__STDC_VERSION__`, `__x86_64__` and `__LP64__`.
- **Lexical.** Line splicing (backslash-newline), and comments anywhere, replaced by one space.
- **Variadic functions:**
  - define them with `stdarg.h`: `va_list`, `va_start`, `va_arg` (int, long, pointer and, from W5, double), `va_end`,
    `va_copy`;
  - this needs the ABI's register save area and the `gp_offset`/`fp_offset`/`overflow_arg_area` walk;
  - pass a `va_list` on to `vprintf`, `vsprintf` and `vsnprintf`;
  - call variadic functions with mixed argument types.

## Categories

`W4 varargs`, `W4 stringize-paste`, `W4 macro-function`, `W4 conditional`, `W4 define`, `W4 include`. A test's category
is the first of these it uses. Many W4 tests use only `#include` plus W1-W3 features: those are `W4 include`.

## Not yet

These are W5:
- unsigned and long arithmetic, though `size_t` must already be 8 bytes, since `strlen` returns it;
- casts, switch, goto and bitwise operators;
- static and extern;
- floats.
