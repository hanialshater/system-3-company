# Wave 3: structs, unions, typedef, enums, sizeof, initializers

Read CONTRACT.md first. W1 and W2 stay in scope (regressions).

## In scope

- **Structs:**
  - definitions, named or anonymous, nested, and self-referential through pointers;
  - members through `.` and `->`;
  - struct assignment and copy;
  - structs as parameters and return values, by value;
  - arrays of structs and pointers to structs;
  - layout: size and alignment per the ABI, padding included.
- **Unions.** The same forms; members overlap at offset 0, and the size is the largest member's rounded to the
  alignment.
- **typedef.** Of any type, including struct, pointer, array and function types; it is block-scoped like variables.
- **enum.** Constants with implicit and explicit values (`enum { A, B = 5, C }`); enum variables are `int`-sized.
- **sizeof and _Alignof.** `sizeof expr` and `sizeof(type)`, results as an integer constant, and `_Alignof(type)`.
- **Initializers:**
  - brace lists for arrays and structs, nested;
  - designated initializers (`.x = 1`, `[3] = 2`);
  - the size of `int a[] = {…}` inferred from its list;
  - `char s[] = "abc"` and `char s[10] = "abc"`;
  - members and elements left out are zero-filled;
  - global initializers that hold addresses: `int *p = &g;`, `char *s = "x";`, arrays of pointers, `&arr[2]`.

## Categories

`W3 unions`, `W3 enums`, `W3 typedef`, `W3 initializers`, `W3 sizeof`, `W3 structs`. A test's category is the first
of these it uses.
