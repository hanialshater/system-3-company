**Decision:** Split by pipeline stage (all four positions agree on this; letters fixed as follows). Slot A = syntax, file work/MOD-A/syntax.mjs: cell-name validation and normalisation (A1..Z99, one letter, 1-99, no leading zero, case-insensitive, normalised to upper case), the formula tokenizer and parser to an AST (precedence loosest first: comparison = <> < > <= >=, then &, then + -, then * /, then ^ right-assoc; unary +/- binds to the next atom so -2^2=4; numbers are digits with at most one dot; strings double-quoted no escapes; TRUE/FALSE any case; NAME(args) parses as a call node). Parse failure is never thrown: it returns an error node that evaluates to #VALUE!. Wave 2: A adds ref and range nodes and refsOf(ast). Slot B = values, file work/MOD-B/values.mjs: the value model and error constants, coercion (empty->0, booleans->1/0, numeric text->number, other text->#VALUE!), text form for &, operator semantics (arithmetic, ^, &, comparison with case-insensitive strings), #DIV/0!, non-finite->#VALUE!, left error wins, 9-decimal rounding, display formatting, and typing of non-formula input (" -2.5 "->-2.5, "12abc" stays text). Slot C = evaluator, file work/MOD-C/eval.mjs: walks the AST with a context, delegating operators to B; owns the function registry (empty in wave 1 so every call -> #NAME?; wave 2 functions are added here); wave 2 ref lookups go through the context. Slot D = store and recalculation, file work/MOD-D/store.mjs: per cell raw text, parsed AST and cached value; evaluate is injected (D does not import C); wave 2/3 dependency graph, dirty propagation, topological recalc and cycle detection live only here. SHEET (work/SHEET/sheet.mjs) is thin wiring only, no spreadsheet logic. Owners: dev-1 owns A and D plus ARCH and SHEET orders; dev-2 owns B and C (semantics and later functions). This keeps the wave 2 hot spots (refs in A/D, functions in C) split across both builders. A failing acceptance category is routed to the owner of the slot that holds that behaviour.

VALUES: JS number, string, boolean; "" = empty. Errors are frozen singleton objects {error:"#DIV/0!"} owned by B: ERR.DIV0, ERR.VALUE, ERR.NAME (wave 2/3 add ERR.REF, cycle error, only in B). Never strings, so typed text "#DIV/0!" stays text. Only normalizeCell throws; everything else returns values.
SLOT A exports: normalizeCell, parseFormula, refsOf. normalizeCell(name) -> "A1" (upper case) or throws Error for anything not one letter + 1..99 without leading zero (incl. non-strings). parseFormula(src) where src is the text after "=" -> AST, never throws; bad syntax returns {type:"error",code:"#VALUE!"}. Grammar: cmp := cat (cmpop cat)*; cat := add ("&" add)*; add := mul ([+-] mul)*; mul := pow ([*/] pow)*; pow := unary ("^" pow)?; unary := [+-] unary | atom; atom := number | string | TRUE | FALSE | NAME "(" args ")" | "(" cmp ")". So -2^2 = (-2)^2 = 4, 2^3^2 = 512. Nodes: {type:"num",value} {type:"str",value} {type:"bool",value} {type:"unary",op,arg} {type:"binary",op,left,right} (op one of + - * / ^ & = <> < > <= >=) {type:"call",name (upper case),args:[node]} {type:"error",code}. Wave 2 adds {type:"ref",cell:"A1"} {type:"range",from,to}. refsOf(ast) -> unique normalised cell names, ranges expanded (wave 1 always []).
SLOT B exports: ERR, isError, errorFromCode, parseLiteral, toNumber, toText, binary, unary, round9, display. errorFromCode(code) -> the ERR singleton. parseLiteral(text) -> number for a trimmed signed plain number (" -2.5 ", "7", ".5"), else the text unchanged. toNumber(v) -> number|error ("" ->0, bools 1/0, numeric text, other text -> ERR.VALUE, error passes through). toText(v) -> string|error (TRUE/FALSE, String(n), "" -> ""). binary(op,a,b) -> value: left error wins, then right; arithmetic via toNumber; / by 0 -> ERR.DIV0; non-finite result -> ERR.VALUE; & joins toText; comparisons return booleans, two strings compared case-insensitively else both toNumber. unary(op,v) -> number|error. round9(n) -> Number(n.toFixed(9)) with -0 -> 0. display(v) -> "" for "", "TRUE"/"FALSE", String(round9(n)), text as is, error.error.
SLOT C exports: evaluate, FUNCTIONS. evaluate(ast, ctx) -> value, never throws; ctx = {get(cell) -> value} (wave 2 adds range(from,to) -> value[][] rows). Error node -> errorFromCode(code); call -> FUNCTIONS[name] ? FUNCTIONS[name](argNodes, ctx, evaluate) : ERR.NAME (args not evaluated for unknown names). FUNCTIONS is an empty object in wave 1. Intermediate values are never rounded.
SLOT D exports: createStore. createStore({evaluate}) -> {set(cell,{raw,ast,refs,value}), clear(cell), get(cell) -> value or "", raw(cell) -> text or ""}. For a value cell SHEET passes ast:null and value; for a formula D computes value = evaluate(ast, ctx) with ctx.get reading its cached unrounded values; waves 2/3 add dependency edges from refs, recalculation of dependents in topological order and cycle detection here only.
SHEET: createSheet() -> {set,get,display}. set(cell,text): key = normalizeCell(cell); text "" -> store.clear(key); starts with "=" -> ast = parseFormula(text.slice(1)), store.set(key,{raw:text,ast,refs:refsOf(ast)}); else store.set(key,{raw:text,ast:null,refs:[],value:parseLiteral(text)}). get(cell): v = store.get(normalizeCell(cell)); numbers returned as round9(v). display(cell) = display(get(cell)).
ARCH.md: dev-1 writes it (order ARCH) verbatim from this decision with one "exports:" line per slot as listed above; dev-2 checks the B and C sections. Interface changes in later waves go through an ARCH amendment by the lead, never a silent edit in a module. · actions: ISS-7, ISS-8
