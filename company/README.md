# The System 3 Company Handbook

System 3 Company makes **60-second interactive lessons**, one idea per card in a vertical feed. A
learner predicts, plays and then sees why. The company is a set of narrow AI agents with a human
founder. It is run on the architecture described in *System 3: Towards Fluent Autonomy*: claims
with addresses, evaluators who see the artifact before the builder's explanation, objections
that travel with decisions, and a constitution that keeps whoever is being judged from editing
the judge.
