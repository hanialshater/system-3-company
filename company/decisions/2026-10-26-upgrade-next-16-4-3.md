# Upgrade Next.js 16.4.0 to 16.4.3 (security patch, C8)

owner: platform-engineer
date: 2026-10-26
status: decided (by the owner, for its branch); ships only with principal-engineer-ops' approval of company/engineering/readiness/2026-10-26-next-16-4-3-upgrade.md and a founder-approved deploy
board: W-2093 · review: company/engineering/reviews/2026-10-25-content-hub-production-review.md (F8, C8)

## Context
`npm audit --omit=dev` on main (`83127c23f`, Next 16.4.0) reports `next` **critical**, range 16.0.0 to 16.4.0:
GHSA-2464-fhr4-w9xw (image optimizer SVG RCE), GHSA-673q-mjm6-r5xr (`use cache` typed-array RCE),
GHSA-p3m5-59mp-jv5r (Server Actions DoS). Main uses no `next/image`, no `"use cache"` and no `"use server"`, so the
exposure is probably low; this record does not claim it is nil. Next 16.4.0's own `next build` now ends with
`SecurityFatalError` (exit 1) after writing its output, so verify and deploys fail on it. The content hub launch
(C8) wants the upgrade before any artifact build, because the frame bundles are built with Next's vendored webpack
and terser (`spike/build.mjs`) and would otherwise be rebuilt.

## Decision
`next` `^16.4.0` → `^16.4.3` (the latest 16.4 patch; the advisories' fix range starts at 16.4.1). Only `next`,
`@next/env` and the `@next/swc-*` binaries move in `package-lock.json`; no new package. React stays 19.2.

Evidence, on this host (Node 22, Linux x64), branch `feat/lesson-frames-pilot`:
- `npm audit --omit=dev`: the `next` critical is gone. One **high** remains: `zod` 4.1.11 (GHSA-mrhx-c7xc-m3w5,
  `<4.6.6`), pulled in by `better-auth`/`better-call` (the auth path). Not in C8's scope, and an auth dependency, so it
  is routed to backend-engineer on the board rather than changed here.
- `next build` (`npm run build`): rc 0, no SecurityFatalError. Wall 144.2, 145.1, 147.0 s (median 145.1 s). On
  16.4.0 the same tree took 152.5 s and exited 1 on the nudge.
- `npm run typecheck`: pass. Client first-load JS of `/`: 265,474 B gz (10 scripts); `/d/*` static pages: 1,646.
- The full suite results are in the branch handoff (company/ops/progress.md, top entry).

## Rests on
`npm audit --omit=dev` output on 2026-10-26; the builds above.

## Revisit if
An advisory lands on 16.4.3, or a 16.5 is needed for an API.
